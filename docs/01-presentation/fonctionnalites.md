# Fonctionnalités du produit

Les fonctionnalités réellement implémentées dans le dépôt sont les suivantes.

- inscription, connexion, refresh JWT, disponibilité du nom d’utilisateur,
- profils de développeurs avec bio, pays, compétences, réputation,
- publication de projets et d’annonces de rôles,
- candidature à des projets et acceptation / refus des membres,
- tableau Kanban, sprints, tâches et discussion d’équipe,
- forum avec questions, réponses, votes et tags,
- revue de code et commentaires sur pull requests,
- intégration GitHub pour import et synchronisation,
- messagerie privée,
- notification et feed d’activité,
- gestion administrativa et modération,
- hackathons et opportunités.

Ces fonctions sont réparties entre les contrôleurs backend et les pages du frontend.
