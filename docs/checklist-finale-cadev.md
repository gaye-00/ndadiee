# Validation finale CADEV

Cette page est une porte de validation synthétique, pas une seconde checklist détaillée. Pour les vérifications et preuves par domaine, utiliser la [checklist des livrables CADEV](09-conformite-cadev/checklist-livrables.md).

## Décision avant remise

- [ ] Le règlement applicable et le calendrier ont été confirmés auprès de l’organisateur.
- [ ] Le commit ou tag présenté est identifié et reproductible.
- [ ] Les exigences de dépôt, d’hébergement et de démonstration sont appuyées par les preuves demandées.
- [ ] Les parcours montrés ont été répétés sur la version qui sera présentée ; toute étape indisponible est omise ou signalée.
- [ ] L’équipe a validé ses informations, ses contributions et sa déclaration d’utilisation de l’IA.
- [ ] Les licences directes et transitives ont été examinées avant toute déclaration de conformité.
- [ ] Les limites et éléments non vérifiables sont présentés sans les confondre avec des fonctionnalités déployées.
