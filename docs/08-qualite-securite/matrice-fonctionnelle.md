# Matrice fonctionnelle de Ndadiée

**Date de revue :** 6 novembre 2026.
Cette matrice décrit les éléments repérés dans le dépôt ; elle ne vaut pas validation d'un parcours en fonctionnement.

## Légende

- **Présent (code)** : les principaux éléments backend/frontend sont raccordés dans le code ; leur parcours réel n'a pas été exécuté ici.
- **Partiel** : capacité codée mais interface, étape ou intégration attendue manquante ou limitée.
- **Non implémenté** : aucun endpoint ou parcours correspondant repéré.
- **Non vérifiable** : preuve d'exécution ou environnement externe manquant.
- La colonne **Tests** inventorie les tests ciblés existants. La suite backend de référence consignée précédemment comptait 313 réussites ; cette phase n'a pas relancé les tests.

## Limites de la matrice

- Un endpoint et un appel frontend alignés n'établissent ni la disponibilité du backend ni la réussite de la requête.
- Les tests unitaires listés couvrent des unités/services, pas nécessairement les contrôleurs, le navigateur, les permissions en contexte réel ou les dépendances externes.
- Aucun test frontend de composant/parcours n'a été repéré dans l'inventaire.
- Les écrans contenant des données de démo ne prouvent pas qu'une instance de bêta est alimentée avec des données effectives.

Pour les constats et recommandations détaillés, consulter l'[audit fonctionnel approfondi](./audit-fonctionnel.md).
