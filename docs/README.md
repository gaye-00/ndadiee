## Méthodologie de cette documentation

Cette documentation est rédigée en fonction du code réellement présent dans le dépôt, avec un souci de distinction claire entre :

- fonctionnalités implémentées et vérifiables,
- fonctionnalités partiellement implémentées,
- éléments qui nécessitent une confirmation de l’équipe,
- configurations de développement versus production.

Les références de code sont fournies dans les fichiers qui documentent chaque domaine. Les détails de sécurité, de déploiement et de compatibilité légale restent à confirmer par l’équipe ou par la CI / environnement de production.
